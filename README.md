# 불어 단어 카드

[EternalOlive/memory-cards-web](https://github.com/EternalOlive/memory-cards-web)에서 갈라져 나온 학습 사이트의 개인용 포크입니다. Anki에서 가져온 프랑스어 단어 덱을 iPhone 홈 화면 앱과 PC 브라우저에서 복습하는 데 씁니다.

## 사용

- GitHub Pages 주소를 열고 설정 → GitHub 연결에서 학습 데이터가 들어 있는 Gist를 연결합니다. 브라우저마다 한 번씩 연결합니다.
- iPhone에서는 Safari나 Chrome의 공유 메뉴에서 「홈 화면에 추가」로 설치하면 전체 화면 앱으로 열립니다. 새 버전은 앱을 완전히 닫았다 열면 반영됩니다.
- Anki 덱은 `import_anki.py`로 .apkg 파일을 변환해 가져옵니다. Front/Back 필드가 카드 앞뒤가 되고, `[sound:…]` 표기는 화면에서 숨깁니다. 오디오 재생은 없습니다.
- 이 저장소에는 개인 카드, 학습 기록, Gist 식별자, 토큰을 넣지 않습니다.

## 이 포크에서 더한 것

원본 파일은 그대로 두고 새 파일 두 개를 마지막에 불러옵니다. 기존 동작을 바꿀 때는 전역 함수를 감싸는 방식으로 덮어씁니다.

- `sien-mine.js`
  - 덱 목록의 각 덱 줄에서 하루 신규·복습 한도를 바로 조절하고, 오늘만 더 푸는 추가분을 둘 수 있습니다. 추가분은 Asia/Seoul 04:00에 끝나며 기존 기기 간 동기화 경로로 공유됩니다.
  - 한도가 늘어 남은 카드가 많아지면 이어 풀기가 새 카드를 섞어 넣습니다.
  - 폰에서 탭 막대를 모든 화면에 유지하고, 설정을 팝업 대신 페이지로 엽니다.
  - 카드 앞면을 프랑스어(`lang="fr"`)로 표시합니다.
- `mine.css`
  - 폰 화면: 카드 내용 가운데 정렬, 44px 터치 영역, 16px 입력창, 가로 흔들림 방지.
  - 홈 화면 앱: 상태바와 홈 인디케이터 영역까지 내용이 흐르고, 탭 막대는 홈 인디케이터 위에 뜹니다. iOS 26의 짧은 뷰포트 문제(WebKit 301108)를 `min-height`로 보정합니다.
  - 버튼 크기와 한 줄 라벨, iOS 글자 세로 중앙 보정.
- `manifest.webmanifest`: 홈 화면 앱 이름·아이콘·시작 주소.

스터디 룸(공부 현황, 찌르기, 리더보드)은 원본과 같은 서버를 그대로 씁니다. 보내는 데이터의 형식과 집계 기준은 바꾸지 않습니다.

## 검사

```
node --test *.test.cjs
```

원본의 출제 순서·일정·병합·네트워크 검사에 더해 `mine.test.cjs`가 한도 계산, 추가분 만료, 상위·하위 덱 분리, 발음 표기 제거, 홈 화면 앱 판정을 검사합니다. 화면은 Playwright Chromium의 iPhone 프로필로 확인합니다. 설정 페이지 제목을 빠르게 다섯 번 두드리면 뷰포트와 안전영역 값을 보여 주는 진단 줄이 나옵니다.

## 원본 반영

원본 저장소의 변경은 `origin/main`을 기준으로 받아들입니다. 기존 파일의 수정은 새 파일을 불러오는 줄과 캐시 버전(`?v=`) 값뿐이라 충돌 없이 합칠 수 있습니다. 원본의 변경 이력은 이 저장소의 커밋 기록에서 볼 수 있습니다.
