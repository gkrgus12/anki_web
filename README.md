# 내 일본어 카드

[EternalOlive/memory-cards-web](https://github.com/EternalOlive/memory-cards-web)의 개인용 포크입니다. 원본 사이트와 다른 사용자의 저장소는 변경하지 않습니다.

## 사용

본인 GitHub Pages 주소에서 GitHub 연동을 열고 기존 학습 데이터가 들어 있는 Gist를 연결합니다. 각 브라우저에서 한 번씩 연결해야 합니다. 공개 사이트 저장소에는 개인 카드, 학습 기록, Gist 식별자, 토큰을 넣지 않습니다. GitHub의 secret Gist는 주소를 아는 사람이 읽을 수 있는 비목록 데이터입니다.

Obsidian Memory Cards Sync 2.1.1은 노트를 텍스트와 강조 범위로 보냅니다. 앞면 예문은 노란색/회색 링크 강조와 줄바꿈을 유지하고, 뒷면 번역 예문도 강조를 유지합니다. 글자 선택과 복사가 가능합니다.

기존 카드 ID, 학습 기록과 복습 예정일을 보존합니다. 새 답변부터 Anki 방식의 SM-2를 적용합니다. 전환 후 모든 기기에서 개인용 주소를 사용합니다. 원본 사이트는 새 학습 기록 형식을 읽지 못합니다.

## 동기화 구조

- Obsidian 노트 파일은 Syncthing으로 전달합니다. 원문 변경은 기존 기기별 원문 변경 기록을 사용합니다.
- 각 브라우저의 답변은 먼저 로컬 전송 대기열에 저장하고, 그 브라우저의 Gist 기록 파일에 추가합니다. 다른 기기의 파일을 덮어쓰지 않습니다.
- 응답이 끊겨도 동일한 변경 ID로 재확인하여 중복 답변을 피합니다.
- 카드와 덱의 삭제 기록은 계속 유지하여 오래된 데이터가 돌아와도 재등록하지 않습니다. 기본 덱도 덱 메뉴에서 삭제할 수 있습니다. 하위 덱과 소속 카드는 기존 확인창에 표시된 범위대로 함께 삭제되며, 삭제 전 학습 기록은 보존됩니다.
- 동일 카드에 여러 기기가 답변하면 답변 기록은 모두 보존합니다. 현재 복습 상태는 변경 순서상 마지막 답변의 상태를 사용하며 동시 답변을 재계산하지는 않습니다.
- 같은 브라우저의 여러 탭은 Web Locks로 전송을 직렬화합니다. 최신 Chrome/Edge 및 Android Chrome을 사용합니다.
- 세션 설정은 브라우저별입니다. 웹사이트 자체를 오프라인에서 새로 여는 기능은 보장하지 않습니다. 열린 페이지의 미전송 답변은 재연결 때 전송합니다.

## 구현

- sien-render.js: 텍스트 및 허용한 강조/링크만 DOM으로 표시합니다.
- sien-study.js: 변경 기록 병합, 삭제 보호, 재전송 중복 제거를 담당합니다.
- sien-app.js: 기기별 Gist 전송, 로컬 전송 대기열, 기존 화면 연결을 담당합니다.
- sien.css: 카드 텍스트의 줄바꿈과 강조 색상입니다.

스터디 현황은 원본과 같은 Study Companion 서버에 로그인하여 확인합니다. 개인 카드와 복습 데이터 저장은 GitHub Gist가 담당합니다.

## 검사

node --test study.test.cjs sm2.test.cjs로 병합 로직을 검사합니다. 브라우저 검사에는 격리된 합성 카드와 모의 Gist를 사용하여 채점, 재시작, 두 기기 병합, 삭제, 네트워크 오류와 재시도를 확인합니다. 실제 Android 기기 테스트는 별도 확인이 필요합니다.

학습 화면은 Space/Enter로 답을 보고 1~4 또는 Z/X/C/V로 채점합니다. 버튼에 다음 복습 간격을 표시하고 출처·품사·JLPT는 작은 속성 영역에 표시합니다. GitHub 동기화는 접속과 화면 복귀, 답변 및 편집 직후에 수행합니다. 종료 시에는 전송 대기 기록을 keepalive 요청으로 보내고, 강제 종료나 오프라인으로 완료하지 못한 기록은 다음 접속에서 같은 ID로 재전송합니다.

## 개인 학습 설정 (2026-10-16)

- 발음, 각 뜻, 예문, 작은 출처 영역으로 뒷면을 구분합니다. v1 내보내기의 첫 문단 필드 구분자를 화면에서만 줄바꿈하며 카드 본문과 강조 위치는 변경하지 않습니다.
- 키보드 설정은 입력 배치에서 변경합니다. 중복 키를 거부하고 기본값으로 복원할 수 있습니다. 컨트롤러 설정과 폴링은 제거했습니다.
- SM-2 신규 단계는 1분/10분, 졸업 1일, 쉬움 4일입니다. 재학습은 10분이며 복습 간격·카드별 ease·지연·상한·fuzz를 반영합니다. 가져온 Anki 로그의 마지막 factor를 ease 초기값으로 사용하며 이후 SM-2 상태에 보존합니다. 기록이 없는 카드는 2.5를 사용합니다.
- 기존 학습 기록을 일괄 재생하거나 만기를 재설정하지 않습니다. 저장된 `fsrs` 키는 기존 동기화/암기상태 연결을 위한 호환 형식이며, 새 일정은 `sien-sm2.js`가 계산합니다. `sm2` 필드와 답변 로그에 결과를 함께 보관합니다.
- Anki의 [SM-2 설명](https://faqs.ankiweb.net/what-spaced-repetition-algorithm.html)과 [학습 단계](https://docs.ankiweb.net/deck-options.html#learning-steps)를 참고합니다. 웹의 분산 시드는 별도 구현이므로 Anki 프로그램과 무작위 간격이 항상 일치한다는 뜻은 아닙니다.
- 찌르기는 활성 창에서 5초마다 확인하며 별도 팝업에 보관합니다. 확인 전까지 다른 안내가 덮지 않습니다. 서버는 같은 계정의 첫 수신 기기에 전달하므로 다른 사이트/Anki가 먼저 받은 알림을 이 사이트가 다시 가져올 수는 없습니다. 사이트가 닫힌 상태의 운영체제 푸시 알림은 지원하지 않습니다.

격리된 브라우저에서 신규/재학습 단계, 재접속, 진행 중 답변 되돌리기, 사용자 키 변경, 알림 수신을 검증합니다. 실제 사람에게 찌르기를 보내는 검사는 하지 않습니다.
